# Python for Noob

A beginner-friendly Python repository containing basic learning examples and small scripts to practice the fundamentals of Python programming.

## Repository structure

- `Basics/`
  - `hello.py` - a simple hello world example.
  - `variable.py` - shows basic variable usage.
  - `while.py` - demonstrates while loops.
  - `cargame.py` - a small interactive program using loops and conditionals.
  - `randomnum.py` - demonstrates random number generation.
  - `1q.py` through `5q.py` - numbered practice scripts.
  - `6q.py/` - contains a small module/example showing how to define and import Python code across files.

## Getting started

1. Install Python 3 if it is not already installed.
2. Open a terminal in the repository root.
3. Run a script with:

```bash
python Basics/hello.py
```

Replace `hello.py` with any other script file in `Basics/` to try different examples.

## Notes

- A `.gitignore` file is included to keep editor settings, virtual environments, and compiled Python artifacts like `__pycache__/` out of version control.
- This repository is intended for learning and practice, so feel free to add your own small programs and example scripts.
